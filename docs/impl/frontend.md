Written Sat 21.11.2026 ~19:30 from `design/README.md`, the 21 mockups in `design/mockups/` (template + `renderVals()` data), `design/tokens.json`, `docs/PLAN.md`, `docs/flow1_build_plan.md`, `backend/riskminer/api/*` and `config/config.example.yaml`.
Audience: the two frontend coding sessions (F1, F2) and the backend planners, who should match the data contracts in §2 (or tell F1/F2 where they differ; the adapter layer absorbs small differences).

Hard rules carried over: Polish UI copy, English code and comments; **no U+2014 (em dash) and no U+00B7 (middle dot)** anywhere in copy (a test enforces it, §5); permissive licences only; the frontend never calls an LLM, only `/api/*`; unfinished screens are hidden by feature flags, never shown broken.

## 0. Decisions at a glance

| Topic | Decision | Why |
|---|---|---|
| Stack | React 19.3 + Vite 8 + TypeScript **5.9.3** (pinned: `openapi-typescript` peers on `typescript ^5`) + Tailwind 4.3 + shadcn/ui (CLI 4.23, Radix) | decided by the team; versions checked with `npm view` (§4) |
| Router | **TanStack Router** (file-based, `@tanstack/router-plugin`, `autoCodeSplitting`) | typed params and zod-validated search params (Monitoring drill-down, table filters live in the URL), `beforeLoad` guards for login/flags, loaders that prefill TanStack Query, one file per route so two sessions never edit the same routes file |
| Server state | TanStack Query 5 + `openapi-fetch` client typed by `openapi-typescript` from `/openapi.json`, plus hand-written contract types (§1.3) for endpoints that do not exist yet | screens build now, switch to real endpoints one by one |
| Mocks | **MSW 2.15** (browser + node), handlers grouped per domain, switchable per group by env, URL and a dev panel; mock responses carry `x-rm-mock: 1` and the page shows "dane przykładowe" | screens built before endpoints exist; no silent fake data in the demo |
| Charts | custom SVG for `ScenarioLines` and `EvidenceFlow` (d3-scale, d3-shape, d3-sankey: layout only, React renders); div bars for range/similarity/tornado/balance (as in the mockups); recharts 3 only for generic charts added later (backtest, histograms) | the two key charts need pixel control, end-label collision handling and click-to-trace; logic stays pure and unit-tested |
| Map | MapLibre GL 6 via `@vis.gl/react-maplibre` 8, **no basemap tiles** (blank style + our GeoJSON), labels and "+N d" pills as HTML markers (no glyph server needed) | matches the mockup's flat choropleth, no external tile/glyph dependency or tile licence |
| PDF | react-pdf 11 (pdf.js 6.5), lazy chunk, only on 1.3 | the default Red Pen view renders page **text** with marks (exactly like the mockup); "Pokaż oryginał PDF" switches to react-pdf |
| State | URL search params for shareable UI state, React state for local, Query for server state; no global store | fewer moving parts |
| Lint/format | Biome 2.6 | one fast tool, MIT/Apache |
| Tests | Vitest 5 + Testing Library + MSW node; Playwright 1.65 + `@axe-core/playwright` (MPL-2.0, dev-only tool) | §5 |

### 1.3 Data layer

```
src/api/schema.gen.ts      npm run gen:api   → openapi-typescript http://localhost:8000/openapi.json (committed, so CI needs no backend)
src/api/client.ts          http = createClient<paths>({ baseUrl: '', credentials: 'include' }); $api = createQueryClient(http)
                           middleware: x-rm-mock header → MockBadge; non-2xx → throw ApiError { status, detail, requestId }
                           contractFetch<T>(path, init) for endpoints not yet in the schema (same middleware)
src/api/contracts/*.ts     the TypeScript interfaces in §2 (the frontend's side of the contract)
src/api/adapters/*.ts      backend type → contract type, one function per endpoint when shapes differ
src/features/*/api.ts      queryOptions factories + mutations; the ONLY place screens get data from
```

- Screens never call `http`/`contractFetch` directly; they call `features/x/api.ts`, so switching an endpoint from "contract + mock" to "generated + real" touches one file.
- When an endpoint lands: run `npm run gen:api`, replace `contractFetch<T>` with `$api` (or keep the contract type and add an adapter), and add a compile-time check in `src/api/contracts/check.ts`: `const _x: Contract = adapt(null as unknown as components['schemas']['XOut'])`.
- Query keys from `lib/keys.ts` (`['analysis', id]`, `['analysis', id, 'simulation']`, `['project', id, 'card']`, `['monitoring', 'regions', level, parent, filters]`, …).
- QueryClient defaults: `staleTime: 60_000`, `retry: (n, e) => !(e instanceof ApiError && e.status < 500) && n < 1`, `refetchOnWindowFocus: false`.
- Primary data: route `loader` calls `queryClient.ensureQueryData(opts)`; the screen uses `useSuspenseQuery(opts)`; the route's `pendingComponent` is the screen skeleton and `errorComponent` is `RouteError`. Secondary panels (chat, side lists) use `useQuery` with inline `DataState`.
- Long jobs: analysis run, import sessions and enrichment jobs are polled with `refetchInterval: (q) => isActive(q.state.data) ? 1500 : false`. (SSE can replace polling later without changing screens.)
- Money from the backend is a Pydantic `Decimal`, so `amount` arrives as a **string**; formatters accept `string | number | null`.
- Writes go through `useMutation` with `onSuccess: invalidate(keys)`; review decisions and allocation choices are optimistic (§2).
- Downloads (pack DOCX/PDF/CSV/JSON, CSV exports): `fetch` → blob → `<a download>` in `lib/download.ts`, filename from `Content-Disposition`.

### 1.4 Mock layer (MSW)

- `mocks/fixtures/<screen>.ts`: the mockup data ported 1:1 from each `renderVals()` into the contract shapes of §2 (Steklin, AN-2026-0014, the 5 review items, 22 projects, 16 voivodeships, the 172 radar signals). Typed with the contract interfaces, so a contract change breaks the fixture at compile time.
- `mocks/handlers/<domain>.ts`: every handler is wrapped:
  ```ts
  export const mockable = (group: MockGroup, h: HttpHandler) =>
    // resolver runs only if the group is mocked; otherwise passthrough() to the real backend
  ```
  The index (`mocks/handlers/index.ts`) uses `import.meta.glob('./*.ts', { eager: true })`, so adding a domain file never edits a shared file.
- Groups: `session, dashboard, ask, analyses, redpen, simulation, allocation, pack, import, projects, project_card, graph, documents, audit, review, catalogue, monitoring, settings`.
- Switch: `VITE_MOCKS=all | none | <comma list>` in `.env.development`; dev-only override `?mocks=analyses,simulation` (persisted in `localStorage['rm.mocks']`, wrapped in try/catch) and a `MockPanel` (dev only, bottom-left) with a checkbox per group and "przeładuj".
- Stateful mocks where the flow needs it: the analysis draft (chips edits), review queue (save/undo advances), import session (question → answered → test run → running → done), allocation choices. State lives in module memory and resets on reload.
- `session` mock role from `localStorage['rm.mockRole']` (`public | expert | admin`) so e2e and demos can switch modes.
- Every mocked response sets `x-rm-mock: 1`; the client records it and `MockBadge` shows a small pill "dane przykładowe" in the page header. Production builds default to `VITE_MOCKS=none`; a group can be enabled in production only if it is marked `demoSafe` in `mocks/config.ts` (figures that are real per README §10), and the badge always shows.
- The same handlers run in Vitest (`msw/node`, `onUnhandledRequest: 'error'`) and in Playwright's mock project.
- Pinned to MSW 2.15 (stable `import { http, HttpResponse } from 'msw'` API). MSW 3 moved imports to `msw/http`; upgrade later if wanted.

### 1.5 Auth and public mode

The backend has no session concept yet (only Caddy basic auth for the whole site). Contract the frontend needs:

```ts
GET  /api/auth/me      → Session                    // 200 with role 'public' when not logged in
POST /api/auth/login   { username, password } → Session   // sets HttpOnly cookie rm_session
POST /api/auth/logout  → 204
GET  /api/nav/counts   → NavCounts                  // expert only
interface Session { role: 'public' | 'expert' | 'admin'; name: string | null; initials: string | null }
interface NavCounts { review_open: number; monitoring_new: number }
```

- `useSession()` = `useQuery(sessionQuery)` with `staleTime: Infinity`, refetched after login/logout. `isPublic = role === 'public'`.
- The frontend guard is UX only; every write endpoint must check the role server-side.
- Header (README §4): public shows `Monitoring, Nowa inwestycja, Projekty`, "Zapytaj" pill, black "Zaloguj się" pill, no counts, no "Więcej"; logo → `/monitoring`. Logged in shows `Pulpit, Monitoring (12), Nowa inwestycja, Projekty, Przegląd (37), Katalog` + `Więcej` (`Import i źródła, Historia, Ustawienia`), "Zapytaj" and the account button (initials, menu: name, "Wyloguj"); logo → `/`. Counts only for work waiting on the user.
- Public-mode rules applied by shared components, not per screen:
  - `ReviewStatusBadge` renders `proposed` as "niezweryfikowane" (no link to Przegląd) when public.
  - `LoginRequired` wraps actions that need login ("Obserwuj", "Zgłoś jako przypadek", "Dodaj dokument", "Wzbogać ponownie", "Popraw powiązanie"): public click opens `/zaloguj?redirect=…`.
  - Project cards: lessons with `review_status !== 'approved' | 'edited'` are dropped client-side as a second line of defence (the backend filters first).
  - Chats on public data handle `429` with "Za dużo pytań naraz. Spróbuj za minutę."
- Login screen: one card, username + password + "Zaloguj się", error "Nieprawidłowy login lub hasło." Demo credentials are published in the submission text, never in the code.

### 1.9 Polish formatters (`src/lib/format.ts`, `plural.ts`, `dates.ts`)

`Intl` for `pl-PL` does **not** group 4-digit numbers (`1234`), but the design does (`1 060 d`, `4 268`), so every number goes through one helper with `useGrouping: 'always'` and a final pass that turns any group space (U+0020, U+202F) into U+00A0.

| Function | Example in → out |
|---|---|
| `fmtInt(n)` | `11184` → `11 184` (NBSP) |
| `fmtDec(x, d)` | `0.82, 2` → `0,82`; `1.17, 2` → `1,17` |
| `fmtMoney(m, opts)` | `{amount:'2131590.00', currency:'PLN', vat_basis:'gross'}` → `2 131 590,00 zł`; `{vat:true}` → `2 131 590,00 zł brutto`; `null` amount → `brak`; currency ≠ PLN → `1 234,00 EUR` |
| `fmtMoneyShort(x, unit)` | `10.59, 'mln'` → `10,59 mln zł`; `20.7, 'mld'` → `20,7 mld zł`; `560, 'tys'` → `560 tys. zł` |
| `fmtPct(x, {signed, digits})` | `40.3, {signed}` → `+40,3%`; `-12.7` → `−12,7%` (U+2212 minus); `0.36` with `{fromShare:true}` → `36%` |
| `fmtPp(d)` | `5` → `+5 pp`; `-3` → `−3 pp`; `0` → `''` |
| `fmtDays(n, {short, signed})` | `277` → `+277 dni`; short → `+277 d`; `1060` → `+1 060 d`; `1` → `+1 dzień` |
| `fmtMonths(x)` | `16.3` → `16,3 mies.` |
| `fmtDate(iso)` | `'2024-06-04'` → `04.06.2024` (date-only strings are split, never `new Date()`, so no timezone shift) |
| `fmtDateTime(iso, {short})` | `21.11.2026 13:40`; short `21.11 13:40` (`timeZone: 'Europe/Warsaw'`) |
| `fmtN(n)` | `84` → `n = 84` (NBSP around `=`); `[1390, 9794]` → `n = 1 390 i 9 794` |
| `isInsufficient(n, min = 10)` | `n < 10` → render "za mało danych" (`MIN_N` mirrors `analytics.insufficient_n`) |
| `plural(n, ['umowa','umowy','umów'])` | `Intl.PluralRules('pl')`: one/few/many; also `sygnał/sygnały/sygnałów`, `ryzyko/ryzyka/ryzyk`, `dzień/dni/dni` |
| `fmtBzp(s)` / `fmtNip(s)` | `2024/BZP 00349631/01` unchanged (mono); `8792466869` → `879 246 68 69` |
| `fmtScore(x)` | `0.82` → `0,82` |

Empty values render `brak`, never a dash. All of them are pure and unit-tested (§5).

### 1.10 Shared contract types (`src/api/contracts/common.ts`)

```ts
export type VatBasis = 'net' | 'gross' | 'unknown';
export interface Money { amount: string | number | null; currency: string | null; vat_basis: VatBasis | null }
export type Origin = 'SOURCE' | 'CALC' | 'AI' | 'CASE';          // CASE = "przypadek" (case memory) role
export type ReviewStatus = 'auto' | 'proposed' | 'approved' | 'edited' | 'rejected';
export type EvidenceState = 'nie_ma_w_paczce' | 'dokument_nie_wspomina' | 'brak_potwierdzenia' | 'potwierdzono_brak';
export interface EvidenceKey { claim_table: string; claim_id: number; claim_field?: string }   // → GET /api/evidence (exists)
```
